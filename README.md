# Flashcards Quiz App

A premium, responsive flashcards application built with React, Tailwind CSS, and GSAP.

## Features
- **Dynamic Cards**: Responsive design that adjusts to content size.
- **3D Flip Effect**: Smooth animations using GSAP.
- **Favorites System**: Save difficult questions to practice them separately.
- **Shuffle & Reset**: Shuffle the deck or start over with one click.
- **Mobile Optimized**: Custom bottom navigation and horizontal chips for action buttons.
- **Keyboard Support**: Navigate using arrow keys and flip with space/enter.

## Tech Stack
- React
- Tailwind CSS (v4)
- GSAP (GreenSock Animation Platform)
- Lucide React (Icons)

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
